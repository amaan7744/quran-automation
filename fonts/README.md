# Fonts

## DigitalKhattIndoPak.otf

An IndoPak-style Quran font matching the traditional Mushaf script used in
India, Pakistan, and Bangladesh — based on the *Al Majeed 13-line IndoPak
Mushaf* reference layout.

- **Source:** https://github.com/DigitalKhatt/indopakfont
- **Author:** Amine Anane, sponsored by Tarteel Inc.
- **License:** SIL Open Font License 1.1 (see `LICENSE-IndoPak.txt`) — free
  to use, embed, and redistribute as part of this project's output videos,
  including commercially. The only OFL restriction is that the font file
  itself may not be sold standalone.

This file is also fetched fresh in CI (`.github/workflows/main.yml`) so the
committed copy here is mainly for local/offline rendering and as a pinned
fallback.

The English caption font (Poppins) is unchanged, licensed separately under
OFL and fetched in CI from Google Fonts.
